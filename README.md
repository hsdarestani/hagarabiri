# HAA&D — Hagar Abiri Architecture & Design

Minimal, timeless company website for HAA&D, prepared for Cloudflare Pages.

## Cloudflare Pages

- Production branch: `main`
- Framework preset: `None`
- Build command: leave empty
- Build output directory: `public`

The site is intentionally image-independent for launch. A future projects/work section is already prepared so project imagery can be added later without redesigning the page structure.
